# CalcLoan 靜態試算工具

`calcloan/` 是可獨立使用的純前端試算工具，包含：

- `index.html`：新青安＋一般房貸比較
- `general.html`：一般房貸比較
- `adjustment.html`：預售屋面積找補試算

## 啟動方式

頁面沒有建置流程或外部 JavaScript 依賴。面積找補頁使用 ES Modules，建議從專案根目錄啟動本機靜態伺服器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory calcloan
```

然後開啟：

```text
http://127.0.0.1:8000/adjustment.html
```

## 面積找補資料儲存

- 輸入內容會自動寫入目前瀏覽器的 `localStorage`。
- 清除瀏覽器網站資料可能造成紀錄遺失。
- 頁面上方提供 JSON 匯出與匯入，可用於備份或跨裝置還原；匯入會先驗證資料，失敗時不覆蓋目前內容。

## 找補計算規則

- 面積差額：實際登記面積 − 契約面積。
- 誤差率：面積差額 ÷ 契約面積 × 100%。
- 分項單價：契約分項價款 ÷ 契約面積。
- 所有金額欄位以萬元輸入；計算時轉為整數新台幣，結果以完整 `NT$` 金額顯示。
- 未套用上限價差：面積差額 × 分項單價，最後四捨五入至整數新台幣。
- 總面積優先採第四條契約總面積；未輸入時才以主建物、附屬建物與共有部分加總暫估，不含土地及車位。
- 第四條第一項依契約書層級輸入，平方公尺與坪會互相換算；主建物、附屬建物與共有部分會同步至找補表。
- 面積換算在輸入與儲存階段保留最多 8 位小數，畫面結果才依顯示規則四捨五入。
- 房屋分項價差各計一次；主建物及總面積誤差率只作為契約門檻判讀，不另行重複計價。
- 「部分資料小計」只加總已可計算的分項；三個房屋分項的必要面積與價款全部齊全時，才顯示「完整未調整參考淨額」。
- 依目前已提供契約確認無雨遮，附屬建物無須扣除雨遮，直接使用契約與實際登記面積計算。
- 2% 情境僅為測試明載假設下的金額影響，與未調整價差、待確認契約結論分開顯示。
- 誤差絕對值必須「大於 3%」才顯示可能符合第六條第三項的警示，等於 3% 不觸發。

## 已知限制

- 使用者已提供契約第四條第一項及第六條；房地分項價款、土地條款及其他變更設計約定仍須依正式完整契約核對。
- 2% 上限如何落實至各分項，需核對完整契約與適用規範；假設情境不產生武斷的正式應退／應補金額。
- 土地資料只供紀錄，不套用第六條房屋找補公式。
- 工具是核對及初步試算用途，不是法律意見，也不等於建商最終結算。

## 驗證方式

JavaScript 語法：

```bash
node --input-type=module --check < calcloan/js/adjustment.js
```

單元測試：

```bash
node --test calcloan/js/adjustment.test.mjs
```

人工檢查至少包含：

- 主建物 20 坪、實際 19.8 坪、價款 800 萬，應為 −0.2 坪、−1%、每坪 40 萬、價差 −8 萬。
- 20 坪對 19.4 坪為 −3%，不觸發超過 3% 警示；19.39 坪為 −3.05%，應觸發。
- 375px 寬度無頁面水平溢出；面積表在手機版改為各類別獨立直向卡片，不需橫向捲動。
