# CalcLoan 架構說明

## 專案定位

calcloan/ 是可獨立開啟及部署的純靜態房貸比較工具，不依賴根目錄網站的 CSS、JavaScript 或圖片。

工具提供兩種模式：

- index.html：比較「新青安＋一般房貸」組合方案。
- general.html：比較純一般房貸方案。

兩頁都能新增多家銀行，或建立同一家銀行的多種年限、寬限期與利率方案。

## 頁面切換

兩頁頂端共用 loan-mode-nav：

- 新青安＋一般房貸 → index.html
- 一般房貸 → general.html

選單使用 sticky 定位，向下查看結果時仍停留在畫面頂端。aria-current 用來標示目前頁面。

## 資料模型

### 共同輸入

- 房屋總價，使用 calcloan.housePrice 儲存在 localStorage，兩頁共用
- 最在意的比較方式

組合貸款頁另有新青安可用額度。

### 每個銀行方案

- 銀行／方案名稱
- 貸款成數，預設 80%，可改為 75%
- 開辦費
- 帳管費
- 其他一次性費用

組合貸款方案包含兩段條件：

- 新青安：年限、寬限期、利率
- 一般房貸：年限、寬限期、利率

純一般房貸方案只有一段一般房貸條件。

方案由 offer-template 建立。按下「新增銀行方案」時，JavaScript 複製模板並綁定刪除事件。

## 本金拆分

~~~text
總貸款 = 房屋總價 × 貸款成數
~~~

組合貸款再拆成：

~~~text
新青安本金 = min(總貸款, 新青安可用額度)
一般房貸本金 = 總貸款 - 新青安本金
~~~

純一般房貸頁將總貸款全部視為一般房貸本金。

## 還款公式

目前假設固定年利率、寬限期內只繳利息，寬限期結束後採本息平均攤還。

### 寬限期

~~~text
每月利息 = 剩餘本金 × 年利率 ÷ 12
~~~

寬限期內本金不減少。

### 本息平均攤還

~~~text
月付 = 本金 × 月利率 × (1 + 月利率)^期數
       ÷ ((1 + 月利率)^期數 - 1)
~~~

利率為 0 時：

~~~text
月付 = 本金 ÷ 剩餘期數
~~~

### 組合方案月付

~~~text
組合月付 = 當月新青安月付 + 當月一般房貸月付
~~~

兩段寬限期不同時，還款階段可能依序為寬限期、部分寬限、本金攤還。

## 顯示指標

每個方案會產生：

- 自備款
- 初期月付
- 寬限期後月付
- 最高月付
- 月付跳升
- 全期總利息
- 前 5 年利息
- 銀行相關費用
- 每月本金、利息與剩餘本金

費用加總：

~~~text
銀行相關費用 = 開辦費 + 帳管費 + 其他一次性費用
利息與費用 = 計算期間內利息 + 銀行相關費用
~~~

此處的「成本」不包含償還的貸款本金。

## 最佳方案判斷

| 選項 | 比較值 |
|---|---|
| 全部繳完，利息與費用最少 | 全期利息＋三項銀行費用 |
| 寬限期後，每月繳最少 | 所有寬限期結束後的組合月付 |
| 任何月份都不要繳太高 | 整段期間的最高單月繳款 |
| 寬限期結束，月付增加最少 | 寬限期後月付－初期月付 |
| 只看前 5 年，利息與費用最少 | 前 60 個月利息＋三項銀行費用 |

排序只用來選出最佳方案，不改變比較表順序。比較表依方案建立順序呈現，最佳方案以 is-best 樣式及「最佳」標籤標示。

主要比較值相同時，依序使用總利息及最高月付作為次要排序條件。

## 每月明細

點選比較表中的方案後，明細區會更新為該方案。展開明細可查看：

- 期數
- 還款階段
- 當月月付
- 當月利息
- 當月償還本金
- 當月結束後剩餘本金

明細預設收合，避免 30 至 40 年資料讓頁面一開始過長。

## 互動流程

~~~text
載入頁面
  → 建立兩個預設銀行方案
  → 自動執行第一次試算
  → 保持在頁首設定區

使用者修改條件
  → 按下「開始比較」
  → 驗證欄位與寬限期
  → 建立逐月還款資料
  → 找出最佳方案
  → 更新建議、比較表與明細
  → 捲動到方案比較區

按下「清除並重設」
  → 只移除 CalcLoan 的房屋總價 localStorage
  → 房屋總價與所有方案恢復預設值
  → 回到頁面設定區
~~~

## RWD

- 桌機版並排顯示貸款條件。
- 手機版將共同條件壓縮排列。
- 手機版將年限、寬限期、利率維持同列。
- 手機版隱藏輸入框內重複單位，避免數值被截斷。
- 比較表與每月明細可水平捲動。
- 兩頁切換選單固定在畫面頂端。

主要斷點：

- 900px：貸款區塊由並排改為上下排列。
- 640px：套用手機版緊湊配置。

## 驗證

JavaScript 語法：

~~~bash
node --check calcloan/js/calculator.js
node --check calcloan/js/general-calculator.js
~~~

本機查看：

~~~bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory calcloan
~~~

網址：

~~~text
http://127.0.0.1:8000/
http://127.0.0.1:8000/general.html
~~~

至少檢查新增及刪除多個方案、75% 與 80%、不同寬限期、五種最佳方案判斷、三種月付、每月明細及桌機與手機版面。

## 維護注意事項

- 不要把銀行利率或政策條件寫死為不可修改規則。
- 新增費用欄位時，需同步調整兩份 HTML 模板與兩份 JavaScript。
- 新增最佳方案指標時，需同步調整下拉選單、標籤、說明、顯示格式與測試。
- 修改還款公式時，需同步驗證組合貸款及純一般房貸。
- 頁面只在 localStorage 儲存房屋總價，不儲存銀行方案，也不傳送任何資料。
- 試算結果不是銀行核貸承諾，應以銀行正式對保資料為準。
